# RÉCIT

**A digital platform for theatre, performances, and stories.**

RÉCIT is a theatre-focused web project designed to bring theatre plays, live performances, and theatre-related editorial content together in one place.

## Project Vision

The goal of RÉCIT is to create an engaging, modern, and accessible platform for theatre lovers, with a distinctive visual identity inspired by the atmosphere of the stage.

## Planned Features

- **Bilingual experience:** Persian and English language support.
- **Light and dark themes:** Two visual modes for a flexible browsing experience.
- **Theatre plays and performances:** A dedicated space to explore plays and upcoming performances.
- **Theatre magazine:** Editorial content, articles, and stories related to theatre.
- **Responsive design:** An experience adapted to desktop, tablet, and mobile screens.

## Technologies

The initial project uses:

- HTML
- CSS
- JavaScript

Additional technologies may be introduced as the project evolves.

## Project Status

**In development.**

The project is currently at its initial setup stage. Features listed above are planned and may not yet be implemented.

## Getting Started

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension.
